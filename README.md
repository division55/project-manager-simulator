# Project Manager Under Pressure

## A Process Model Decision Simulator

Project Manager Under Pressure is an interactive browser-based simulation that places the user in the role of a software project manager handling realistic project situations and making decisions under pressure.

The decisions made throughout the simulation are analyzed to identify which software process-model philosophy — Waterfall, Agile, Spiral, or Incremental — is most reflected in the user's management approach.

---

## Overview

The project is designed as an educational simulation for understanding Software Engineering process models through practical decision-making rather than theoretical questions alone.

The user works through a simulated software project involving:

- Changing requirements
- Budget constraints
- Team member turnover
- Technology risks
- Client feedback
- Scope creep
- Schedule delays
- Security vulnerabilities
- Quality issues
- Last-minute requirements
- Final delivery decisions

Each situation requires the user to choose how they would respond as the project manager.

The system tracks these decisions and generates a final process-model profile based on the user's overall decision pattern.

---

## Key Features

### Virtual Workplace

The simulation is presented as a virtual work environment containing:

- Email
- Team Chat
- Calendar
- Project Dashboard
- Notifications
- Project Files
- Decision History

### Realistic Project Communication

The user receives workplace-style communication including:

- Client emails
- Team discussions
- Finance updates
- QA alerts
- Project notifications
- Meeting reminders

### Project Scenarios

The simulation contains 12 major project-management scenarios covering:

1. Changing Requirements
2. Budget Warning
3. Key Developer Leaving
4. Technology Risk
5. Client Rejection
6. Scope Creep
7. Team Conflict
8. Schedule Slippage
9. Security Vulnerability
10. Quality Crisis
11. Last-Minute Requirement
12. Final Delivery

### Dynamic Project State

The project state changes as decisions are made.

The simulation tracks:

- Budget
- Schedule
- Risk
- Quality
- Team Morale
- Client Satisfaction

### Process Model Analysis

The decision system represents four major software process models:

- Waterfall
- Agile
- Spiral
- Incremental

The user does not directly select a process model. Instead, the final profile is generated from the decisions made throughout the simulation.
